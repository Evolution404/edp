# EDP / 北信源安全 U 盘公开资料与盘上元数据交叉研究

日期：2026-08-29

## 目的与证据原则

本研究只用于补充对 EDP 安全 U 盘产品/协议背景的理解，不以互联网资料替代真实设备证据。

证据分三类：

1. **公开资料直接确认**：专利、上市公司公告/招股书、政府采购文件等明确写出的产品行为。
2. **项目真实盘/代码实证**：本仓库真实 Lexar/SanDisk/aigo 捕获、golden fixtures 和 native validators 已重复验证的低层结构。
3. **推断/待确认**：公开资料和低层实测之间概念上吻合，但公开资料没有给出字节级映射。

任何 media classifier、密码验证、sector geometry、key derivation 或 raw write 行为的修改，仍必须有真实 fixture + golden test 支撑。

## 一、公开资料直接确认的产品背景

### 1. 北信源长期存在“移动存储管理系统及安全 U 盘”产品

北信源 2013 年年度报告列出“北信源移动存储管理系统及安全U盘2.16.0”，并列有相关安全测评/认证。2025 年年度报告仍列出同名产品的网络安全专用产品安全检测证书，说明这是一条长期维护的产品线，而不是短期 PoC。

来源：

- 深圳证券交易所披露的《北京北信源软件股份有限公司2013年度报告全文》
  - https://disc.static.szse.cn/disc/disk01/finalpage/2014-04-15/98191ffb-ec4c-43d8-84ad-7119a4e31c76.PDF
- 深圳证券交易所披露的《北京北信源软件股份有限公司2025年年度报告全文》
  - https://disc.static.szse.cn/disc/disk03/finalpage/2026-04-30/7a6af570-72c6-4d2d-b7c3-445edf0687b8.PDF

### 2. 安全 U 盘采用专用介质、芯片级安全和 USB 标签认证

北信源招股资料对“北信源安全U盘系统”的公开描述包括：采用专用安全 U 盘，提供芯片级移动存储数据安全管理技术，并结合 USB 移动存储介质标签认证技术实现入网认证和控制。

同一资料还描述“移动存储介质使用管理系统”采用底层驱动、设备识别、数据存储转换、标签认证，对介质进行认证、解码分析和信息重构。

来源：

- 北信源招股说明书/招股资料公开页面：
  - https://vip.stock.finance.sina.com.cn/corp/view/vISSUE_RaiseExplanationDetail.php?id=975892&stockid=300352
  - https://money.finance.sina.com.cn/corp/view/vISSUE_RaiseExplanationDetail.php?id=969566&stockid=300352

这与项目当前的“不能只把它当普通 MBR U 盘”结论一致：介质存在产品私有标签/metadata、区域定义和加密逻辑。

## 二、三区域模型：公开资料与真实盘最重要的交叉点

### 1. 授权专利明确写出三个区域

北信源专利 CN105141614A / CN105141614B《一种移动存储设备的访问权限控制方法及装置》明确说明：

- 移动存储设备可以写入普通标签、加密标签或干扰标签；
- 写入加密标签时，将设备划分为 **启动区、交互区、保密区**；
- 通过密码验证后，对交互区和保密区进行访问控制。

来源：

- Google Patents CN105141614A：
  - https://patents.google.com/patent/CN105141614A/zh

这是目前找到的最高质量公开资料之一，因为它直接来自该产品厂商的专利，并明确描述了加密介质的区域模型。

### 2. 政府采购技术要求使用“启动区、交换区、保密区”术语

公开政府采购文件的移动存储技术要求写明：写入加密标签后，普通移动存储设备可分为 **启动区、交换区、保密区**；交换区和保密区还可与启动区组合成双分区形态。

来源：

- 内蒙古自治区政府采购公开招标文件：
  - https://www.ccgp-neimenggu.gov.cn/gpx-bid-file/150001/gpx-tender/2024/7/24/402881d290e24c970190e40c6c883475.pdf?accessCode=6761a8b3e93e6406f31549f75241acc3

这说明专利中的“交互区”在实际产品/采购语境中也常写作“交换区”。项目 UI 使用“交换区”是合理的产品术语。

### 3. 旧产品操作资料也描述三分区/双分区/整盘加密

网络上可找到历史“USB 标签制作工具”操作资料，描述：

- 缺省三个分区：启动区、交换区、保密区；
- 启动区与交换区二合一；
- 整盘加密；
- 启动区包含启动程序，未注册计算机可通过启动程序访问交换区。

来源（第三方文档镜像，只作为产品行为线索，不作为低层格式权威来源）：

- https://www.renrendoc.com/paper/111731210.html

## 三、与当前真实盘低层结构的对应关系

### A. 项目已通过真实盘/golden 确认

当前仓库对标准加密 EDP 盘已经验证：

- LBA4：存在序列/标签相关 marker；
- LBA7：解码后存在 `EDPF` record layout；
- LBA11：参与稳定设备 identity；
- LBA12：包含 volume metadata / 区域描述；
- 标准产品逻辑区域对应 type：
  - type 1：启动区；
  - type 2：交换区；
  - type 4：保密区；
- 交换区、保密区具有独立密码/credential 语义；
- encrypted logical block mapping 使用项目已验证的 SM4 透明转换路径；
- key/password CRC、设备 identity、起始 sector/size 等由真实 fixture 和 native validator 共同约束。

这些属于 **真实盘/代码实证**，证据优先级高于网上产品说明。

### B. 公开资料与实测高度吻合但不能过度外推

公开专利确认三个逻辑区域及密码控制，这与 type 1/2/4 在语义上高度吻合。

但公开资料目前 **没有** 直接说明：

- 启动区的数值 type 就是 `1`；
- 交换/交互区 type 就是 `2`；
- 保密区 type 就是 `4`；
- 元数据固定存放于 LBA4/LBA7/LBA11/LBA12；
- `EDPF` record 的字段偏移；
- LBA7 的具体混淆/解码算法；
- LBA11 device ID 的确切构造；
- LBA12 encryption/CRC 字段偏移；
- password CRC / file-key CRC 算法；
- SM4 key derivation 和 sector mapping。

因此不能把“公开资料确认三区域”写成“公开专利确认了我们的 type 1/2/4 与 LBA12 字节格式”。后者仍是项目自己的逆向/实测结论。

- `2016107120395`：《快速识别移动存储设备的方法和装置》；
- `2015105639641`：《一种移动存储设备的访问权限控制方法及装置》。

来源：

- 巨潮资讯《北信源2019年年度报告摘要》：
  - https://static.cninfo.com.cn/finalpage/2020-04-30/1207685497.PDF

公开专利索引可确认 CN106354680A/B 对应“快速识别移动存储设备的方法和装置”，申请人为北京北信源软件股份有限公司。

目前搜索到的公开索引还不足以把这个“快速识别”专利与本项目 LBA4/LBA7 classifier 的具体 sector 算法建立字节级对应，因此这里只记录为**相关研究线索**。

后续若取得完整专利文本，应重点检查：

- 是否描述固定扇区读取；
- 是否描述设备标签 magic / serial；
- 是否描述无需完整枚举文件系统即可识别专用介质；
- 是否能解释旧版/新版免密改造盘的识别差异。

## 五、EDP / VRV 命名需要避免误判

公开资料中还存在“VRV-EDP”作为北信源其他安全管理产品/一体机简称的记录。它能证明厂商使用 EDP/VRV 相关命名，但 **不能据此推断盘上的 `EDPF` magic 就一定代表某个公开英文全称**。

同样，网络搜索 `EDP`、`EDPF` 会出现大量无关结果：

- 日本 I-O DATA 的 EDP 系列普通 U 盘；
- 计算机视觉 Edge Drawing / EDPF；
- 与北信源安全介质无关的其他产品。

研究时必须以“北信源/VRV + 安全U盘/移动存储 + 专利/产品证据”联合筛选。

## 六、对当前 media classifier 的影响

### 不改变现有结论

当前识别策略仍应坚持真实盘证据：

- 只有标准加密盘进入 EDP Drive 管理；
- 旧版免密改造盘、最新版免密改造盘、普通 U 盘直接让系统接管；
- 不能仅凭某一个 type 字段识别产品类型；
- classifier 必须每次基于真实介质 metadata 重新验证，不依赖缓存假设。

公开资料对“三区域/标签/密码访问控制”提供背景支持，但没有足够信息去放宽或重写低层 classifier。

## 八、后续研究方向

1. 获取 CN106354680A/B 完整正文，寻找“快速识别”对固定 sector/tag 的描述。
2. 搜索早期 VRV EDP 驱动、USB 标签制作工具、EdpEDisk/相关 binary 的合法公开安装介质或文档，仅做静态研究。
3. 对 aigo/Lexar/SanDisk 多厂牌真实 fixture 比较 LBA4/LBA7/LBA11/LBA12 的稳定字段和厂牌差异。
4. 给 Studio 增加“证据级别”视角时，可把字段标成：已知 magic / 已验证字段 / unknown bytes，避免把未知字段臆测命名。
5. 不进行真实盘 raw-sector 写实验来验证未知字段；需要变异实验时只在复制出的 synthetic fixture 上进行。

## 结论

公开资料已经能强力确认 EDP/北信源安全 U 盘的**产品级模型**：专用/加标签介质、三逻辑区域、密码控制、移动存储策略管理。

公开资料目前仍没有披露本项目最关键的**字节级 on-disk metadata 格式**。LBA4/LBA7/LBA11/LBA12、`EDPF`、type 1/2/4、CRC、SM4 等结论继续以真实盘捕获和 golden validators 为准。
